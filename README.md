# 🌤️ Skyline

Dashboard de clima interativo que permite pesquisar cidades e visualizar as condições meteorológicas em tempo real. 
A interface adapta ícones e elementos visuais de acordo com as condições climáticas, proporcionando uma experiência dinâmica e intuitiva.

🌐 <a href="https://becskyline.vercel.app/">Ver Projeto</a>

---

## 🎯 Funcionalidades

- 🔍 Pesquisa de cidades
- 🌡️ Condições meteorológicas em tempo real
- 📍 Busca por localização atual
- 🕒 Previsão para as próximas horas
- 📅 Previsão para os próximos dias
- 📱 Layout responsivo

## 🚀 Como Executar

1. Clone o repositório
   
   ```bash
   git clone https://github.com/becsnr/skyline.git
   cd skyline
   ```

2. Instale as dependências

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento

   ```bash
   npm run dev
   ```

4. Abra o endereço exibido no terminal
